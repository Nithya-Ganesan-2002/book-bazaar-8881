# BookBazaar Frontend

Features:
- Next.js App Router, light minimal UI
- Browsing, search, preview modal
- SSG/ISR friendly with `revalidate`
- SEO: metadata, sitemap, robots
- Responsive layout (header/nav, sidebar, main grid)

Env:
- NEXT_PUBLIC_SITE_URL: public base URL for metadata, sitemap, robots
- NEXT_PUBLIC_API_BASE (future): API base URL when backend is integrated

Commands:
- npm run dev
- npm run build
- npm start
- npm run lint
